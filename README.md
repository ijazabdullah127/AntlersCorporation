# Antlers Corporation - Technical Services Provider

A modern, responsive website for Antlers Corporation, a reliable technical service provider specializing in internet solutions, security camera systems, Cable TV support, and home security services.

## 🌟 Features

- **Responsive Design**: Fully responsive website that works on all devices
- **Modern UI/UX**: Clean, professional design with smooth animations
- **Multi-page Website**: Complete website with multiple pages including home, about, contact, FAQ, and legal pages
- **24/7 Service Information**: Dedicated sections for showcasing round-the-clock technical support
- **Contact Integration**: Multiple contact methods including email, phone, and location
- **Interactive Elements**: Smooth animations, sliders, and interactive components

## 🛠️ Technologies Used

- **HTML5**: Modern semantic markup
- **CSS3**: Advanced styling with animations and responsive design
- **JavaScript**: Interactive functionality and dynamic components
- **Bootstrap 5**: Responsive grid system and UI components
- **Font Awesome**: Icon library for consistent iconography
- **Swiper.js**: Modern touch slider
- **jQuery**: JavaScript library for DOM manipulation
- **Animate.css**: Cross-browser CSS animations

## 🚀 Getting Started

### Prerequisites

- A modern web browser (Chrome, Firefox, Safari, Edge)
- A local web server (optional, but recommended for development)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/ijazabdullah127/AntlersCorporation.git
   cd AntlersCorporation
   ```

2. **Open with a web server** (recommended)
   ```bash
   # Using Python (if installed)
   python -m http.server 8000
   
   # Using Node.js (if you have live-server installed)
   npx live-server
   
   # Using PHP (if installed)
   php -S localhost:8000
   ```

3. **Or open directly**
   - Simply open `index.html` in your web browser
   - Note: Some features may not work without a web server due to CORS policies

### Usage

1. Navigate to `http://localhost:8000` (or your chosen port)
2. Explore the different pages and features
3. Test responsiveness by resizing the browser window
